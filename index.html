1. 수집하는 정보와 저장 위치

이 앱은 별도의 서버를 운영하지 않습니다. 아래 정보는 전부 사용자의 기기 안에만 저장되며, 개발자를 포함해 그 누구에게도 전송되지 않습니다.

  • 측정 기록 (팔굽혀펴기·윗몸일으키기 개수, 3km 달리기 시간)
  • 훈련 로그, 체감 난이도 응답
  • 위치 정보(GPS) — 러닝 중 이동 거리·페이스 계산 용도로만 사용되며, 기기에만 저장됩니다
  • 알림 시각, 목표 날짜 등 앱 설정값

2. 위치 정보(GPS) 사용 안내

러닝 훈련 중 실제 이동 거리와 페이스를 계산하기 위해 위치 정보 접근 권한을 요청합니다.

  • 위치 정보는 실시간으로 기기 내에서만 계산되며, 외부 서버로 전송되지 않습니다.
  • 위치 권한을 허용하지 않아도 앱은 정상적으로 동작하며(스톱워치 기반으로 대체), GPS 관련 기능(실측 거리·페이스·경로)만 제한됩니다.
  • 위치 측정은 사용자가 러닝을 직접 시작했을 때만 이루어집니다. 안드로이드 앱에서는 러닝 중 화면을 끄거나 다른 앱을 사용해도 측정이 이어지며, 이때 알림창에 "달리기 측정 중"이 항상 표시됩니다.
  • 러닝이 끝나거나 훈련 화면을 나가면 위치 측정은 즉시 종료됩니다. 앱을 사용하지 않는 동안 위치를 수집하는 "항상 허용"(백그라운드 위치) 권한은 요청하지 않습니다.
  • 언제든지 기기 설정에서 위치 권한을 취소할 수 있습니다.

3. 제3자 제공

수집한 정보를 제3자에게 제공하거나 판매하지 않습니다. 서버 자체가 없으므로 물리적으로 전송할 대상이 없습니다.

4. 데이터 보관 및 삭제

  • 모든 데이터는 사용자의 기기(앱 내부 저장소)에만 보관됩니다. 단, 휴대폰의 안드로이드 백업 기능이 켜져 있으면 운영체제가 사용자 본인의 Google 계정에 앱 데이터를 백업할 수 있으며, 개발자는 이 데이터에 접근할 수 없습니다.
  • 앱을 삭제하거나 설정에서 "전체 데이터 초기화"를 실행하면 모든 기록이 영구적으로 삭제됩니다.
  • 설정 탭의 "내보내기" 기능으로 자신의 데이터를 JSON 파일로 직접 백업할 수 있습니다. 파일을 어디로 보낼지(드라이브, 메신저 등)는 사용자가 공유 화면에서 직접 선택합니다.
